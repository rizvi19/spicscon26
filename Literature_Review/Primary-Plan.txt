Core problem:
GPS does not work well indoors. WiFi-based positioning is widely available but noisy due to RSSI fluctuation, multipath, interference, and body shadowing. Visible-light positioning can be accurate but suffers from blockage, line-of-sight loss, and illumination variation. Static fusion is weak because the reliability of WiFi and light changes over time. Therefore, I want to design an adaptive hybrid localization framework.

Proposed system pipeline:
Indoor environment
→ WiFi RSSI-like signals + visible light intensity signals
→ DSP denoising using EMA/median/moving average filters
→ location probability generation
→ graph signal processing over indoor grid/room topology
→ RL-based adaptive fusion weights
→ final position estimate
→ self-healing behavior under blockage/noise

Simulation plan:
Create a 10m × 10m indoor room.
Use a 10 × 10 grid, so there are 100 possible location cells.
Place 2 or 3 WiFi access points.
Place 4 LED/light anchors.
Generate walking trajectories for one person.
Generate WiFi RSSI-like signals using a path-loss model:
RSSI = P0 - 10n log10(distance) + noise + multipath/body-shadowing disturbance
Generate visible-light intensity signals using an inverse-square-like model:
light_intensity = LED_power / distance² + angle/noise effect - blockage loss
Create multiple scenarios:
S1: clean condition
S2: WiFi multipath/noisy condition
S3: visible-light blockage condition
S4: mixed dynamic condition with both noise and blockage

RL design:
Keep the RL simple and feasible. Use a lightweight Q-learning/contextual-bandit-style adaptive fusion policy unless DQN is easy to implement quickly.
The RL agent should not directly solve the full localization problem from scratch. Instead, it should choose fusion weights or fusion modes.
Example actions:
A0: WiFi-heavy fusion
A1: visible-light-heavy fusion
A2: balanced fusion
A3: graph-prior-heavy fusion
A4: self-healing/recovery mode
Reward:
negative localization error, or +1 if error is below a threshold and -1 otherwise.

GSP design:
Represent the indoor grid as a graph:

* each grid cell is a graph node
* edges connect neighboring cells
* location probability is the graph signal
  Use graph Laplacian smoothing to reduce impossible jumps and make the position estimate spatially consistent.
